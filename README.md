# 🚀 Vector Job

A full-stack MERN-based freelancing and job marketplace platform where clients can post jobs and freelancers can apply, communicate, and collaborate efficiently.

## ✨ Features

### 👨‍💼 Client
- Register & Login
- Create Job Posts
- View Posted Jobs
- View Applicants
- Hire Freelancers
- Chat with Freelancers
- Manage Profile

### 👨‍💻 Freelancer
- Register & Login
- Browse Available Jobs
- Apply for Jobs
- Track Applied Jobs
- Chat with Clients
- Profile Management
- Rating System

### 💬 Communication
- Client-Freelancer Messaging
- Secure JWT Authentication
- REST APIs

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Neerajraj09/vector-job.git
```

### Backend

```bash
cd backend
npm install
npm start
```

Backend runs on:

```
http://localhost:8080
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```

---

## 🔑 Environment

Create a `.env` file inside the backend folder.

Example:

```env
ACCESS_TOKEN_SECRET=your_secret_key
```

MongoDB connection string is configured inside the project.
